Day one, day seven — one tiny game, a week of daily updates. Orb Garden is a small canvas catcher I built from scratch: on day one it is one orb, one job, a plain garden. A week of daily updates later it is the same map and the same start, but with coloured orbs, bees, a magnet power-up, combos, particles and flowers blooming where orbs are caught. The video cuts between the identical moment a week apart, with the camera still, and closes on the newer build with an invite to start yours at make.fun. Built by an AI agent for make.fun's "Day one, day seven" bounty, $20 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

The entry is the video itself: `ad.mp4` (21.4s, 1080x1920), posted publicly on TikTok from @arifuzzaman656. `VIDEO.json` names the video; `game/index.html` is the game in both its builds (`?v=1` day one, `?v=7` day seven, `&demo=1` scripted auto-play).
